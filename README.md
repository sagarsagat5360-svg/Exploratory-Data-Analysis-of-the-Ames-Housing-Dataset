# What Shapes House Prices? — Public project site

Static GitHub Pages site for the Ames Housing exploratory analysis project.

## Publish with GitHub Pages

This folder is the site root. Once it is pushed to a GitHub repository, enable **Settings → Pages → Deploy from a branch**, select the `main` branch and `/ (root)`, then save. GitHub Pages will publish `index.html` from this folder.

The page uses plain HTML, CSS and JavaScript. It does not need a build step or external libraries.

## Files

- `index.html`, `styles.css`, `app.js` — website
- `House_Prices_EDA_Project.pdf` — report and exam preparation
- `house_prices_eda.ipynb` — analysis notebook
- `ames_housing_train.csv` — dataset used for the analysis

## Dataset source

Kaggle, *House Prices: Advanced Regression Techniques*, training split. Kaggle lists the dataset metadata license as MIT. The Ames Housing source is described by De Cock (2011), DOI: https://doi.org/10.1080/10691898.2011.11889627.
